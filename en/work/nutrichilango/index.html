Locate the data before interpreting it

Public information becomes less useful when it cannot be compared or its geographic context is unclear. NutriChilango organizes comparisons and location so people can orient themselves before drawing conclusions.

The design question is not how much information fits on a map, but which distinction someone can understand and what context they need to interpret it responsibly.

Maps as orientation rather than decoration

The published approach structures data before designing the interface. Maps support comparison alongside editorial explanations. Static delivery and scheduled updates separate data publication from content consumption.

  • Expose context and provenance.
  • Provide readable explanations alongside visualizations.
  • Automate publication without hiding its limitations.

Distinguish evidence from representation

The case documents map-led exploration, responsive explanations and a scheduled static-data publishing workflow. This page links those sources rather than attributing unverified impact metrics.

The card is conceptual because the original review did not obtain a valid screenshot. Keeping that distinction visible avoids confusing editorial artwork with product evidence. A comparable data project should explicitly address missing data, source changes and update dates as part of its scope.

What supports this case

The image is conceptual artwork, not a product screenshot. The published case and repository are the implementation sources. No health outcomes or usage metrics are claimed.
